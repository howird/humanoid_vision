# Tracking Scripts

## `track.py`

Tracks humans in a video and extracts 3D mesh information.

```bash
python scripts/track.py path/to/video.mp4
```

### Architecture

The script composes the pipeline stages explicitly rather than hiding them
behind a tracker class. Each frame runs through:

1. **Detection** — `pipeline.detection.run_detection()` /
   `pipeline.detection.filter_small_detections()`
2. **Feature extraction** — `pipeline.feature_extraction.crop_and_preprocess_detections()` /
   `pipeline.feature_extraction.extract_hmr_features()`
3. **Track prediction** — `Tracker.predict()`
4. **Data association** — `pipeline.association.associate_detections_to_tracks()`
5. **Track update** — `pipeline.association.update_matched_tracks()` /
   `mark_unmatched_tracks()` / `initiate_new_tracks()`
6. **Future prediction** — `Tracker.accumulate_vectors()`
7. **Result recording**

The three models are instantiated independently and injected:

- `HMAR` (`humanoid_vision.models.hmar`) — appearance / UV autoencoder
- `HMR2` (`humanoid_vision.models.hmr2`) — pose and shape
- `UVTextureRenderer` (`humanoid_vision.utils.uv_texture_renderer`) — projects
  image evidence onto the UV atlas

### Output

1. **Tracking data** — `<track_dataset>_<video_name>.pkl` in
   `--video-io.output-dir`:

   ```python
   tracklets_data = {
       "frame_001.jpg": {
           "tid": [1, 2, 3],   # track IDs
           "bbox": [...],      # bounding boxes
           "smpl": [...],      # SMPL parameters
           "camera": [...],    # camera parameters
           "3d_joints": [...],
           "2d_joints": [...],
           # ...
       },
       # ...
   }
   ```

2. **Rendered video** — `<base_tracker>_<video_name>.mp4`, written when
   `--render.enable` is set: SMPL mesh overlay with track IDs and boxes.

### Common options

```bash
# Enable rendering
python scripts/track.py video.mp4 --render.enable

# Set output directory
python scripts/track.py video.mp4 --video-io.output-dir ./results

# Process a specific frame range
python scripts/track.py video.mp4 --phalp.start-frame 100 --phalp.end-frame 200

# Adjust detection threshold
python scripts/track.py video.mp4 --phalp.low-th-c 0.9

# Tracking parameters
python scripts/track.py video.mp4 --phalp.max-age-track 50 --phalp.n-init 5

# Reset track association across shot boundaries (PySceneDetect)
python scripts/track.py video.mp4 --detect-shots
```

Run `python scripts/track.py --help` for the full set — the CLI is generated by
`tyro` from `PhalpConfig` in `humanoid_vision/configs/base.py`.

## `track_dataset.sh`

Batch-runs `track.py` over a directory tree of game clips. Edit the game list
and paths at the top of the script, then:

```bash
bash scripts/track_dataset.sh
```

## Troubleshooting

**CUDA out of memory** — lower the render resolution:

```bash
python scripts/track.py video.mp4 --render.res 512
```

**No detections found** — lower the detection threshold:

```bash
python scripts/track.py video.mp4 --phalp.low-th-c 0.5
```

**`<output>.pkl already exists`** — only raised under `--no-overwrite`; the
video was already processed. Drop the flag or choose a different
`--video-io.output-dir`.
